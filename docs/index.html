01 · Research framing

Three questions. One auditable pipeline.

The website separates the research hypothesis from the eventual results. Numbers are only published when backed by a real experiment artifact.

RQ1 · Representation

Does multimodal evidence help?

Compare strong image-only and text-only baselines against the adaptive fusion configuration under the same data and evaluation protocol.

RQ2 · Fusion

Can evidence be weighted adaptively?

Learn modality-specific gates instead of assuming that visual and textual representations should contribute equally to every case.

RQ3 · Reliability

When should the model be questioned?

Expose disagreement and uncertainty so low-confidence or conflicting cases can be studied rather than hidden behind a single score.

05 · Reproducibility

A result should have a trail.

The project treats configuration, data provenance, seeds, checkpoints and evaluation artefacts as part of the scientific result.

02

Record model IDs, dimensions, freezing, optimisation and evaluation settings in YAML.

03

Persist isolated outputs, best checkpoints, histories and split indices for each experiment.

04

Verify

Use automated tests and compilation checks before treating a run as reproducible.

Suggested run trail

configs/default.yaml scripts/prepare_dataset.py scripts/train.py scripts/evaluate.py scripts/run_experiments.py outputs/<experiment>/best.pt outputs/<experiment>/history.json

Evaluation surface

Report multilabel discrimination alongside calibration and selective prediction. Add bootstrap confidence intervals and repeated-seed comparisons before making strong comparative claims.

No headline metric is displayed here until an actual experiment produces it.

Research integrity boundary. MedFusion-X is an experimental research and education framework, not a clinical diagnostic system. The public site intentionally does not fabricate accuracy, AUROC, AUPRC, sensitivity, specificity or clinical claims. ChestX-ray14 contains image-level labels rather than paired free-text radiology reports; the default text pathway is therefore a controlled structured-label prompt experiment, not report-grounded multimodal learning.
07 · Model card

Know what the system can—and cannot—support.

Intended use

Research, coursework, model prototyping, multimodal fusion experiments, uncertainty analysis and reproducibility studies.

Not intended for

Diagnosis, triage, treatment selection, patient management, autonomous clinical decisions or regulatory claims.

Dataset limitation

ChestX-ray14 provides image-level pathology labels. Genuine report-conditioned experiments require a separately licensed and appropriately paired report dataset.

Known risks

Dataset bias, label noise, shortcut learning, foundation-model errors, calibration failure and distribution shift can all affect outputs.

Next evidence required

Independent validation, repeated seeds, confidence intervals, calibration, subgroup analysis, robustness testing and clinically appropriate external review.

Live checkpoint rule

The demo requires a genuine trained checkpoint. If it is unavailable, the application should fail safely rather than invent a prediction.

12 · Interpretability layer

Make model behaviour easier to question.

The upgraded interface keeps the existing outputs while making the evidence pathway more explicit for research inspection.

Modality attribution

Image ↔ text contribution

Inspect mean learned image and text gates alongside the final prediction instead of treating fusion as a black box.

Conflict analysis

Disagreement-aware review

Surface cross-modal disagreement as a dedicated signal for selecting cases for deeper analysis.

Reliability

Uncertainty-aware inspection

Keep uncertainty visible beside model scores so researchers can study confidence quality and selective prediction.

Interpretability boundary. Gate values and disagreement are model diagnostics, not causal explanations and not evidence that a specific anatomical region caused a prediction. Genuine attribution methods and human evaluation remain future research work.
