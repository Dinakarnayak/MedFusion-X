01 · Research framing

From prediction to evidence.

The project is structured around a testable research question rather than a single benchmark score.

RQ1 · Representation

Does multimodal evidence help?

Compare image-only, text-only and image+text configurations under a controlled evaluation protocol.

RQ2 · Fusion

Can the model adapt?

Learn modality-specific gates so the fusion layer can vary its reliance on visual and textual evidence.

RQ3 · Reliability

When should evidence be questioned?

Expose image/text disagreement and an uncertainty signal instead of presenting confidence as certainty.

04 · Reproducible protocol

Designed to be rerun.

The scientific value of the framework depends on being able to reproduce the data split, preprocessing, training configuration and evaluation procedure.

01

Data

Download the authorised NIH ChestX-ray14 corpus and validate paths, labels and image availability.

02

Split

Use explicit validation/test fractions and a fixed random seed for controlled comparisons.

03

Train

Run the selected modality configuration with recorded hyperparameters and checkpoint the best validation model.

04

Evaluate

Report multilabel metrics, calibration/reliability analysis and uncertainty-aware selective behaviour.

05 · Research engineering

Reproducibility is a feature.

Every experimental claim should be traceable to code, configuration, data provenance and an evaluation procedure.

YAML configuration captures dataset paths, model identifiers, embedding dimensions, freezing strategy, fusion parameters, optimisation settings and evaluation thresholds.

06 · Evaluation philosophy

Accuracy is not the whole story.

Medical ML evaluation should distinguish discrimination, calibration, robustness and uncertainty instead of relying on a single headline metric.

Discrimination

Macro-averaged multilabel metrics such as AUPRC are useful when pathology prevalence varies substantially across labels.

Selective prediction

Estimate risk under confidence-based abstention so the model can be evaluated when low-confidence cases are excluded.

Uncertainty & disagreement

Inspect modality disagreement and uncertainty alongside predictions rather than treating probability as clinical certainty.

Research integrity notice. MedFusion-X is an experimental research and education framework. The public site intentionally does not publish fabricated accuracy, AUC, sensitivity, specificity or clinical claims. Results should only be added after the corresponding experiment has actually been run and the evaluation artefacts are available for inspection.

08 · Limitations & next experiments

Where the science should go next.

Current limitations

ChestX-ray14 provides image-level pathology labels rather than paired free-text radiology reports. The present text modality therefore represents a controlled structured-text experiment, not full image-report learning. External validation, subgroup analysis and prospective clinical evaluation are also outside the current scope.

Next research directions

Evaluate genuine radiology-report corpora where licensing permits; add calibration and confidence-interval reporting; test distribution shift; compare alternative fusion operators; perform repeated-seed experiments; and investigate label-specific failure modes and clinically meaningful subgroup robustness.
