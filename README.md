# MedFusion-X

Multimodal medical AI research project combining medical image understanding and clinical text reasoning.

## Project Status

Initial repository scaffold created. The implementation will integrate multimodal Hugging Face models, fusion strategies, evaluation, and reproducible experiments.

## Planned Structure

- `src/` — model and fusion code
- `configs/` — experiment configuration
- `scripts/` — training and evaluation entry points
- `notebooks/` — research experiments
- `tests/` — automated tests
- `docs/` — research documentation
